git status → shows repo state
git add → stages files
git reset → unstages/resets
git diff → shows changes
git commit → saves changes
git branch → manages branches
git checkout → switches/restores
git merge → combines branches
git init → creates repo
git clone → copies repo
git log → shows history
git fetch → gets remote updates
git push → uploads changes
git pull → gets + merges
git rebase → reapplies commits
git rm → deletes files
git mv → moves/renames
git stash → saves temp changes
