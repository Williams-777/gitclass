git status → this shows repo state  
git add → this stages files  
git reset → this unstages/resets  
git diff → this shows changes  
git commit → this saves changes  
git branch → this manages branches  
git checkout → this switches/restores  
git merge → this combines branches  
git init → this creates repo  
git clone → this copies repo  
git log → this shows history  
git fetch → this gets remote updates  
git push → this uploads changes  
git pull → this gets + merges  
git rebase → this reapplies commits  
git rm → this deletes files  
git mv → this moves/renames  
git stash → this saves temp changes
